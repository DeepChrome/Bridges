# Offline — the app with no network at all (docs/PLAYBOOK.md Phase 6).
#
# Run it twice: once online for the baseline, once with the radios off.
#   adb -s emulator-5554 shell svc wifi disable
#   adb -s emulator-5554 shell svc data disable
# …and put them back afterwards with `enable`.
#
#   .\native\tools\walk.ps1 -Flow native\flows\offline.txt -Device emulator-5554
#
# What is expected to work with no network: every lesson and quiz (the device
# voice reads what the collection's recordings would have), the 168 listening
# scenarios (their audio is bundled in the APK, §30l), flashcards, every drill,
# the dictionary, the alphabet. What cannot work is the video library (YouTube),
# and the three Worker features — Say's written feedback, the chapter task and
# Talk — which say so rather than hanging.
